## Deadline

**10.09.2027**

## Tech-Stack

- HTML5 (semantisch)
- Tailwind CSS (Einbindung per CDN `<script src="https://cdn.tailwindcss.com"></script>`)
- VS Code

## Anforderungen

- Semantisches, barrierefreies HTML (WCAG-konform)
- Aktuelle Sicherheitsstandards (z. B. keine unsicheren Inline-Scripts, `rel="noopener"` bei externen Links)

## Branch-Struktur

- `main` – produktiver Stand
- `feature/header-hero` – Michael
- `feature/main-black` – Nicole
- `feature/footer` – Eric

## Setup

```bash
git clone <repo-url>
cd Experience_the_Epitome
```

Datei `index.html` im Browser öffnen oder mit VS Code Live Server starten.
